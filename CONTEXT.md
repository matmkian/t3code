# T3 Code

T3 Code is a multi-surface client for directing coding agents across projects and environments.

## Client surfaces

**Full renderer**:
The broad upstream web client that exposes the complete T3 Code product surface.
_Avoid_: Legacy renderer, old renderer

**Minimal renderer**:
The focused, independently owned web client that keeps a deliberately smaller T3 Code product surface. “Minimal” describes its scope, not its maturity or permanence.
_Avoid_: Prototype, personal renderer, v2 renderer

**Renderer target**:
The selected web client presented inside the shared desktop shell.
_Avoid_: Desktop variant, Electron variant
