# Triage Labels

Use these canonical Linear labels when triaging issues:

| Label | Meaning |
| --- | --- |
| `needs-triage` | The issue has not yet been classified or routed. |
| `needs-info` | More information or a user decision is required. |
| `ready-for-agent` | The issue is sufficiently specified for an agent to implement. |
| `ready-for-human` | The issue requires human judgment, access, or action. |
| `wontfix` | The issue was considered and intentionally will not be implemented. |

Apply the single label that best describes the issue's next required action. Replace stale triage labels as the issue advances.
